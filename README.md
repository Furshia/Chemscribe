"# Materials-Safety-Data-Sheet-MSDS-Word-Maker" 

# What does this program do?

Automates the process of getting chemical material safety data sheets (MSDS), it outputs a word file.




## How to use?
1. Run the program
2. Type the desired chemical name (IUPAC Nomenclature) or chemical formula
3. Select the order of collumns to be present or not in the word file
