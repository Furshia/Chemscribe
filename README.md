# What does this program do?
Automates the process of getting chemical material safety data sheets (MSDS), it outputs a word file.
Essentially a "Materials Safety Data Sheet MSDS to Word Maker" by getting its sources from PubChem: pubchem.ncbi.nlm.nih.gov

## How to use?
1. Run the program
2. Type the desired chemical name (IUPAC Nomenclature) or chemical formula. If gas indicate with '(gas)' i.e. HCl (gas)
3. Select the order of collumns to be present or not in the word file
